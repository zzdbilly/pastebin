# Pastebin Enhancement Plan

## 目标
将基础便利贴改造成功能更完善的文本分享工具

## 新增功能

### 1. 密码保护 🔒
- 创建时可选密码（bcrypt 或简单 SHA256）
- 查看时需要输入密码
- KV 存密码 hash

### 2. 标题支持
- 创建时可填写标题（可选）
- 查看页面显示标题
- 无标题则显示 "Untitled"

### 3. 语法高亮自动检测
- 根据内容自动检测语言
- 创建时可手动指定语言
- 查看页按指定语言高亮

### 4. 管理（暂缓）
- 粘贴后生成管理链接
- 可删除/延长过期

### 5. 暗色模式切换
- 当前已有暗色，加个切换按钮
- 记住偏好（localStorage）

### 6. 更好的首页
- 使用示例
- 最近公共粘贴（可选）

## 技术方案

- 所有逻辑保持单文件 worker.js
- 密码使用 Web Crypto API (SHA-256) 不需要额外依赖
- 首页改进设计
- highlight.js 自动检测语言
